# Google Flow tRPC API — 完整逆向工程报告

通过 FlowKit 扩展代理，逐一向 `labs.google/fx/api/trpc/` 发送请求，经过 7 轮探测，确认了以下接口。

---

## 已确认的 tRPC 端点

### 1. `project.searchUserProjects` ✅ — 列出用户所有项目

| 字段 | 值 |
|------|-----|
| **方法** | `GET` |
| **URL** | `/api/trpc/project.searchUserProjects?input={json}` |
| **必填参数** | `toolName: "PINHOLE"`, `pageSize: number` |
| **可选参数** | `pageToken: string` |

**响应结构：**
```json
{
  "result": {
    "projects": [
      {
        "projectId": "2bc7c7bc-...",
        "projectInfo": {
          "projectTitle": "出图-01",
          "thumbnailMediaKey": "90f3a512-..."
        },
        "creationTime": "2026-08-09T17:22:18.640Z",
        "agentInfo": { ... }
      }
    ]
  }
}
```

> [!TIP]
> 你的账号返回了 **8 个项目**，包含完整的 `projectId`、`projectTitle`、`thumbnailMediaKey` 和 `creationTime`。

---

### 2. `project.getProject` ✅ — 获取单个项目元信息

| 字段 | 值 |
|------|-----|
| **方法** | `GET` |
| **URL** | `/api/trpc/project.getProject?input={json}` |
| **必填参数** | `projectId: string`, `toolName: "PINHOLE"` |

**响应结构：**
```json
{
  "result": {
    "projectId": "2bc7c7bc-...",
    "projectInfo": { "projectTitle": "出图-01", "thumbnailMediaKey": "..." },
    "agentInfo": {
      "defaultGenerationSettings": {
        "imageDefaults": { "imageModelFamilyKey": "narwhal_display" },
        "videoDefaults": { "videoModelFamilyKey": "abra" }
      }
    }
  }
}
```

> [!NOTE]
> 此端点**不返回媒体列表**，只返回项目设置和元信息。

---

### 3. `media.fetchUserHistory` ✅ — 获取用户媒体历史（含完整数据）

| 字段 | 值 |
|------|-----|
| **方法** | `GET` |
| **URL** | `/api/trpc/media.fetchUserHistory?input={json}` |
| **必填参数** | `toolName: "PINHOLE"`, `limit: number`, `type: enum` |
| **type 枚举值** | `MUSIC_FX`, `IMAGE_FX`, `VIDEO_FX`, `MUSIC_FX_DJ`, `BACKBONE`, **`FLOW`** |

**响应结构（54KB，每个 workflow 包含完整媒体数据）：**
```json
{
  "result": {
    "userWorkflows": [
      {
        "name": "CAMS...（base64 编码的内部 ID）",
        "media": {
          "name": "CAMS...",
          "image": {
            "seed": 434004,
            "prompt": "...",
            "modelNameType": "HARBOR_SEAL",
            "workflowId": "3e62da43-...",
            "aspectRatio": "IMAGE_ASPECT_RATIO_SQUARE"
          },
          "mediaGenerationId": {
            "mediaType": "IMAGE",
            "projectId": "2bc7c7bc-...",   // ← 所属项目
            "workflowId": "3e62da43-...",
            "workflowStepId": "CAE",
            "mediaKey": "34df4637-..."     // ← UUID 格式 media ID
          },
          "requestData": {
            "promptInputs": [...],
            "imageGenerationRequestData": {
              "imageGenerationImageInputs": [
                { "imageInputType": "IMAGE_INPUT_TYPE_REFERENCE", "mediaId": "..." }
              ]
            }
          }
        },
        "createTime": "2026-08-10T07:37:21.475Z"
      }
    ]
  }
}
```

> [!IMPORTANT]
> 这是**最关键的端点**！通过 `mediaGenerationId.projectId` 字段可以过滤出某个项目的所有媒体，通过 `mediaGenerationId.mediaKey` 获取 UUID 格式的 mediaId（可直接用于 `media.getMediaUrlRedirect`）。

## 推荐的集成方案

### 获取项目列表
```python
# project.searchUserProjects
await flow_client._send("trpc_request", {
    "url": "https://labs.google/fx/api/trpc/project.searchUserProjects?input=" +
           urllib.parse.quote(json.dumps({"json": {"toolName": "PINHOLE", "pageSize": 50}})),
    "method": "GET",
    "headers": {"content-type": "application/json"},
})
```

### 获取项目内所有媒体
```python
# media.fetchUserHistory → filter by projectId
result = await flow_client._send("trpc_request", {
    "url": "https://labs.google/fx/api/trpc/media.fetchUserHistory?input=" +
           urllib.parse.quote(json.dumps({"json": {"toolName": "PINHOLE", "limit": 100, "type": "FLOW"}})),
    "method": "GET",
    "headers": {"content-type": "application/json"},
})
# Then filter: [w for w in result["userWorkflows"] 
#               if w["media"]["mediaGenerationId"]["projectId"] == target_project_id]
```

### 解析 mediaKey → 签名 URL
```python
media_key = workflow["media"]["mediaGenerationId"]["mediaKey"]
signed_url = await flow_client.resolve_media_url(media_key)
```
